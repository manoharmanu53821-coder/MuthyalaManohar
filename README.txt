MUTHYALA MANOHAR — PORTFOLIO WEBSITE

HOW TO VIEW
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to preview it in a browser.

HOW TO PERSONALIZE
- Open index.html in a text editor.
- Replace YOUR_EMAIL@example.com with your email address.
- Replace the LinkedIn and GitHub placeholder href="#" values with your profile links.
- Update the Projects section as you complete projects.
- Update skills to reflect what you can confidently use.

PUBLISH ONLINE
You can publish this folder using GitHub Pages or another static website host.
Keep index.html, style.css, script.js, and the assets folder together.

The website is responsive and includes your supplied portrait.
